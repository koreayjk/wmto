# 16. 직접 눌러 보는 화면 점검표

로그인한 화면은 자동 점검이 안 되므로, 아래 순서대로 눌러 보시고 **이상한 화면의 주소와 증상**(가능하면 캡처)을 알려 주세요. ✅ 표시할 칸을 복사해 쓰세요. 시험용 계정을 따로 쓰고, 실제 회원 정보가 보이는 화면은 캡처하지 마세요.

준비: 사업가 계정 2개(A=새 회원, B=텐트장), 같은 텐트, 운영진 계정 1개. 텐트장은 관리자 → 텐트에서 B를 "텐트장 지정"해 두세요.

## 0. 시험 계정 만들기 (처음 한 번)
이메일이 여러 개 필요합니다. 한 메일함으로 받으려면 `이름+a@도메인`, `이름+b@도메인`처럼 `+표시`를 붙인 주소를 쓰면 됩니다(지메일 등). 실제 회원과 섞이지 않게 이름에 `[시험]`을 붙이세요.
1. 공개 사이트 `/wmto/apply?type=mentor_join` 에서 사업가 가입 신청을 두 번 냅니다. 둘 다 **같은 시·도**로 하고, **업종은 서로 다르게** 고르세요(같은 텐트에는 같은 업종이 못 들어갑니다). 이름은 `[시험] 새회원`, `[시험] 텐트장`.
2. 관리자 → **회원 관리** → 신청자 두 명에게 "승인·초대". 입회 현황에 "비어 있는 텐트 수"가 보입니다. 초대 메일의 링크로 각각 로그인합니다.
3. 두 사람이 **같은 텐트**에 들어갔는지 관리자 → **텐트**에서 확인합니다(다르면 같은 텐트로 직접 배정).
4. 같은 화면에서 `[시험] 텐트장`을 **텐트장으로 지정**합니다.
5. 운영진 계정으로는 평소 쓰시는 관리자 로그인을 쓰고, 시험이 끝나면 관리자 → 회원 관리에서 시험 회원을 비활성화하세요.
6. 3번째 사람이 필요하면(추천사, 소그룹 시험) 같은 방법으로 한 명 더 신청·승인하세요.

## 1. 사업가(A)
- [ ] 로그인 → 홈: "첫 90일 걸음" 카드, "내 활동 한눈에" 숫자와 기간 탭(90일·1년·전체)
- [ ] 내 정보: 프로필 완성도, 소개·키워드·신앙·선교 마음 저장, 업종 처음 고르기 → 저장 후 업종이 잠기고 "변경 신청"만 보임
- [ ] 내 정보: "메일로 알림 받기" 켜기/끄기(메일 환경변수 설정 전에는 저장만 됨)
- [ ] 일정: 텐트 모임에 "참가 신청/취소", "못 가요 미리 알리기", "모임 순서 보기"
- [ ] 1:1 만남: 상대 고르기 → 기록(사진·동의) → 상대(B)가 확인
- [ ] 소개: 보내기(관심 3단계, 미리 연락) → B가 상태 "성사"로 바꾸고 "감사 남기기" → A에게 알림
- [ ] 손님 초대: 손님/참관/대신 나옴, 같은 연락처 두 번 → 막힘
- [ ] 아카데미: "다 봤어요", 학습 기록 추가·지우기
- [ ] 활동·성장: 점수 7항목과 추이, 회비 안내(청구서가 있을 때), 갱신 기간
- [ ] 내 활동 기록(주별 표, 인쇄)
- [ ] 알림: 목록, 모두 읽음, 왼쪽 메뉴의 안 읽은 개수
- [ ] 추천사: 함께 일한 분에게 쓰기 → 받는 분이 공개/숨김
- [ ] 동역 소그룹: 내 소그룹, 게시판 글
- [ ] 선교에 함께하기: 신청 → 승인 전에는 멘토링·리포트·기금 메뉴가 안 보임
- [ ] 내 정보 권리: 데이터 내려받기(JSON 파일), 탈퇴 요청/취소

## 2. 텐트장(B)
- [ ] 텐트 현황: 건강 지표, 새 회원 걸음과 동행 짝 지정, 먼저 안부 물어볼 분, 업종 변경 신청 승인/거절, 비어 있는 업종
- [ ] 선교 권한: 신청 승인·거절, 직접 열기·닫기
- [ ] 손님 초대: 참석 확인(자기 손님은 못 누름)
- [ ] 월간 점검 기록: 시작 → 저장 → 기록자·날짜 없이 제출 시도(막힘) → 제출 → 잠김, 다음 달 이월 할 일
- [ ] 모임 순서: 시간·담당자 저장, 나눔 발표자 추천, 모임 요약 → 후기 글로 올리기
- [ ] 동역 소그룹: 만들기, 구성원 추가(최대 6명), 빼기, 닫기
- [ ] 갱신 심사(해당 회원이 있을 때)

## 3. 운영진
- [ ] 회원 관리: 입회 현황(업종 비어 있는 텐트 수), 업종 대기 명단, 승인·초대
- [ ] 텐트: 텐트장 지정/해제
- [ ] 선교 권한, 갱신 심사(심사 열기, 미갱신은 운영진만)
- [ ] 일정 등록: 참가 조건(배움 단위·마감·최소·정원)
- [ ] 회비: 계좌·문구 저장 → 청구서 발행 → 입금 확인/면제/취소 → 회원 화면과 알림 확인
- [ ] 탈퇴 요청 처리

## 4. 공개 사이트와 주소
- [ ] `/` (CBC 첫 화면, 한국어)·`/en` — 모바일 폭에서 헤더가 한 줄
- [ ] `/wmto`·`/wmto/en` 과 메뉴 이동, 예전 주소 `/about`, `/apply` 가 `/wmto/...` 로 이동
- [ ] `/wmto/apply?type=mentor_join` 입회 문의 제출 → 관리자에서 신청자로 보임
- [ ] 체험 모드를 껐다면(`DEMO_ENABLED=false`): `/connect/demo` → 로그인 화면으로 이동, "체험하기" 링크 없음

## 5. 문제를 알려 주실 때
- 어느 계정(역할)으로, 어느 주소에서, 무엇을 눌렀을 때, 어떤 문구가 떴는지
- 가능하면 캡처 한 장(개인정보 가리기)

## 텐트 플랜팅
- [ ] 관리자 > 텐트: "텐트 플랜팅" 영역에 배정 대기 사업가와 지역 목록이 보인다
- [ ] 같은 지역에 같은 업종 신청자를 승인하면 새 텐트가 자동으로 생기지 않고 대기로 남는다
- [ ] "새 텐트 세우기"를 누르면 같은 지역에 새 텐트가 생기고 대기자가 배정된다(첫 텐트 이름은 "1텐트"로 바뀐다)
