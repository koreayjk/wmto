# 11. 비즈니스 네트워크 시스템 기능 지도 (숙제 1차)

> ⚠️ **내부 참고 자료.** 다른 서비스를 조사·분석한 내용을 담고 있어 공개 저장소에 두지 않습니다(저장소를 공개로 바꾸기 전에 이 문서를 옮기거나 삭제). 서비스 화면·문구·점수 숫자를 그대로 쓰지 않는 것이 원칙입니다(docs/10).


목적: 크리스천 사업가 네트워크(CBC, 가칭)를 "우리만의 것"으로 만들기 위해, 이런 모임 시스템에 필요한 기능을 **기능 단위로** 나열하고 우리 상태와 맞춰 본다.

> 주의
> - BNI Connect 도움말 센터(support.bniconnect.com)는 자동 접속이 403으로 막혀 **읽지 못했다.** 아래 "일반 모듈" 목록은 일반적으로 알려진 수준이며 **확인되지 않았다.**
> - 확실히 하려면 사용자가 도움말 화면의 **분류·글 제목을 캡처/복사**해서 주면 이 표를 보강한다. (글 본문은 베끼지 않고 기능만 본다.)
> - 원칙은 docs/10 그대로: 이름·숫자·화면·문구를 가져오지 않고 기능 아이디어만 쓴다.

## 우리만의 차별점 (BNI와 다른 축)
1. **선교 권한 층**: 신청→승인 또는 텐트장·운영진 지정으로 WMTO 메뉴 열림. (다음 구현)
2. **모든 것이 한 앱**: 1:1 기록·사진·결제까지 외부 밴드 없이.
3. **크리스천 공동체 요소**: 기도 제목, 감사 나눔, 직업 소명 모임, 선교 후원 연결.
4. **성장 중심 평가**: 점수는 벌점이 아닌 "다음 걸음" 안내, 새싹 기간 완화.

## 다음 숙제 제안 (우선순위)
1. 선교 권한 (요청/승인/지정 + WMTO 메뉴 잠금)
2. 갱신 심사 (단계·기간 기반, 운영자 검토 화면)
3. 아카데미 과정·이수 기록 + 점수 연결 (배움 항목)
4. 업종 대기자 명단 + 입회 심사 흐름
5. 알림 체계 (모임 전 알림, 미확인 1:1 알림)
6. 텐트장 대시보드
7. 결제 (법인·PG 확정 후)

## 사용자 확인 필요
- 도움말 센터 분류/글 제목 캡처 (있으면)
- 이름: CBC 상표 충돌 확인(KIPRIS) 후 확정
- 앞선 질문 6번 항목, 감사 금액 기록 여부, 최소 정원(15), 지표 공개 범위
