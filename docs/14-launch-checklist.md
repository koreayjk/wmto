# 14. 출시 전 점검표 (체험 모드 끄기 · 이름 · 법적 항목)

## 1. 체험 모드 끄기 (스위치 구현됨)
- **끄는 방법(되돌릴 수 있음)**: Vercel 환경변수 `DEMO_ENABLED=false` 를 추가하고 재배포.
  - `/connect/demo` 는 로그인 화면으로 보내고, 체험 계정 세션은 인식하지 않으며, 홈페이지·로그인 화면의 "체험하기" 링크도 숨겨진다.
  - 다시 켜려면 변수를 지우거나 `true` 로.
- **데이터 정리(되돌릴 수 없음 — 확인 후에만)**: 스위치를 끈 다음, 아래 대상을 직접 확인하고 지운다. 이 세션은 삭제를 실행하지 않았다.
  1. `apps/web/supabase/demo/clear_demo.sql` — 가상 회원(`@demo.wmto.invalid`)과 `[데모]` 텐트, 가상 데이터 삭제. 실행 전 `select count(*) from wmto.members where email like '%@demo.wmto.invalid'` 로 대상 수 확인.
  2. Supabase Authentication → Users 에서 체험 계정(`DEMO_ACCOUNT_EMAIL`, 기본 `wmto-demo@example.com`) 삭제. `wmto.demo_viewers` 의 해당 행도 삭제.
  3. SVM 과 공유하는 `public.profiles` 에 체험 계정 행이 생겼다면 그 행만 삭제(SVM 의 다른 데이터는 건드리지 않는다).
- 끈 뒤 확인: 로그아웃 상태에서 `/connect/demo` 접속 → 로그인 화면으로 이동.

## 2. 이름
- 서비스 이름은 **CBC로 확정**(2026-11, `lib/brand.ts` 한 곳, 공개 첫 화면의 "가칭" 표시는 제거). 앱 이름(웹 앱 설치명·탭 제목)은 "CBC Connect" 로 이미 바뀌었다.
- 남은 일: 상표(KIPRIS) 확인(한글·영문 각각, 35·41류 등). 문제가 있으면 `BRAND` 한 줄 수정. 홈페이지 WMTO 사이트 안의 "WMTO Connect" 소개 문구(`messages/*.ts` home.connect)는 선교 사역 사이트의 설명이므로 이름 확정 때 함께 정리.

## 3. 법적·운영 항목 (코드로 끝낼 수 없음)
- 법률 문서 초안(검토 전 게시 금지): 현황표 `docs/15-data-inventory.md`, 개인정보처리방침 `docs/17-privacy-policy-draft.md`, 이용약관 `docs/18-terms-draft.md` — `[ ]` 표시 부분을 정해 변호사에게 전달.
- 개인정보처리방침: CBC 수집 항목(업종·회사·사진·1:1 기록·손님 연락처), 보유 기간, 국외 이전, 종교 관련 정보(민감정보) 동의, 탈퇴·열람 절차 반영 → 변호사 검토.
- 이용약관: 갱신 심사 기준·절차·이의 신청, 점수 사용 범위, 소개에 대한 대가 금지.
- 1:1 사진: 두 사람 동의, 보관 기간·삭제 규칙 명시.
- 다른 서비스 분석 자료(`docs/04`, `05`, `11`, `12`, `13`): 저장소가 공개라면 옮기거나 삭제.
- 결제: 법인·결제 대행사 확정 후 별도 설계.

## 4. 메일 알림(하루 한 번 요약) 켜기
- 회원이 **내 정보 → 메일로 알림 받기**에서 직접 켠 경우에만 동작(기본 꺼짐, 켠 뒤 생긴 알림부터, 끄면 대기분 삭제).
- Vercel 환경변수: `RESEND_API_KEY`, `NOTIFY_FROM_EMAIL`(이미 있으면 그대로 사용, 발신 도메인 인증 필요), **`CRON_SECRET`**(임의의 긴 문자열 — 없으면 발송 경로가 401 로 막힘).
- `apps/web/vercel.json` 의 크론이 매일 23:00 UTC(한국 08:00)에 `/api/cron/mail` 을 호출. 수동 시험: `curl -H "Authorization: Bearer $CRON_SECRET" https://<도메인>/api/cron/mail`.
- 메일 내용은 앱 알림 문구와 같고 다른 사람의 연락처·고객 정보는 담지 않는다. 처리방침에 "알림 메일 발송(동의 기반)" 항목을 추가할 것.

## 5. 회비(수동 계좌이체)
- 관리자 → **회비**: 입금 계좌·안내 문구 저장 → 사업가에게 청구서 발행 → 입금 확인 시 "입금 확인"(또는 면제·취소). 회원은 활동·성장에서 입금 안내(미납일 때만 계좌 표시)를 본다.
- 입금은 갱신 여부와 자동 연동하지 않는다(갱신은 갱신 심사). 결제 대행사(PG)·자동 결제·현금영수증은 법인·사업자 정보 확정 후 별도 설계.
- 회비를 받는 주체(법인/단체)와 영수증·세무 처리, 환불 규정은 반드시 별도로 정할 것.
