# BNI Connect 분석 요청서 (크롬 확장 프로그램의 Claude에게 전달용)

> 사용법: 크롬에서 BNI Connect(`https://www.bniconnectglobal.com/web/dashboard`)에 로그인한 상태로
> Claude 확장 프로그램을 열고, **이 문서 전체를 붙여 넣은 뒤** 아래 "2. 분석 요청"을 시키세요.
> 결과(마지막 "4. 결과 형식"대로 정리된 글)를 복사해서 WMTO 앱을 만드는 대화에 붙여 주시면 이어서 반영합니다.

## 0. 지켜 줄 것

- **읽기만 하세요.** 버튼을 눌러 무언가를 저장·전송·삭제하거나, 설정을 바꾸지 마세요.
- 화면에 보이는 **다른 회원의 실명·연락처·사업 정보·금액 등 개인정보는 적지 마세요.** 화면 구조, 메뉴 이름, 입력 항목, 흐름만 정리합니다. (예시가 필요하면 "홍길동", "OO회사"처럼 가짜 값으로 바꿔 쓰세요.)
- 로그인 정보나 토큰, 주소창의 개인 식별 값은 결과에 넣지 마세요.
- 보이지 않거나 권한이 없어서 못 본 화면은 추측하지 말고 "확인 못 함"이라고 쓰세요.

## 0-1. 빠짐없이 (전수 조사 규칙)

- **모든 메뉴와 하위 메뉴를 하나도 빼지 말고 직접 열어 보세요.** 요약하지 말고, 열어 본 화면마다 항목을 적습니다.
- 탭, 필터, 정렬, 더보기(…), 설정(톱니바퀴), 프로필 메뉴, 알림 아이콘, 도움말·가이드 링크까지 눌러서(읽기만) 확인하세요.
- 목록 화면은 **빈 상태 문구**, 항목 하나를 열었을 때의 **상세 화면**, **작성 화면**(저장은 하지 말고 입력 항목만 확인)을 각각 봅니다.
- 한 번 본 화면도 **PC 폭과 모바일 폭(창을 좁혀서)** 에서 모두 확인하세요.
- 다 본 뒤 마지막에 아래 **확인표**를 채워서, 열어 본 화면 / 못 연 화면을 구분해 보여 주세요. 빈칸이 있으면 이유를 적습니다.

## 1. 배경: 나는 무엇을 만들고 있나

**WMTO 자립선교 비즈니스 네트워크**의 회원 앱 "WMTO Connect"를 만들고 있습니다. BNI Connect를 참고합니다.

- WMTO는 크리스천 사업가(Mentor)가 선교사(Partner)를 가르치고 동행해 선교사가 **스스로 일어서도록** 돕는 네트워크입니다. 후원자(Sponsor)는 재정으로 길을 엽니다.
- 표어는 **More Blessed to Give**. BNI의 "Givers Gain(주는 자가 얻는다)"과 달리, 얻기 위해서가 아니라 **주기 위해** 모입니다.
- 그래서 BNI의 "돈 되는 리퍼럴" 대신 **"나눔과 자립의 과정"**을 기록하고, 활동 점수는 색깔 순위가 아니라 **성장 단계 이름**으로 격려합니다.

### BNI → WMTO 대응 (현재 설계)

| BNI Connect | WMTO Connect |
|---|---|
| 회원 프로필 | 역할별 프로필 (사업가·선교사·후원자) |
| 1:1 미팅 기록 | 멘토링 기록 |
| 리퍼럴 슬립 | 매칭 요청 · 사업가 간 소개 |
| 감사 슬립 (TYFCB) | 감사 편지 (선교사 → 멘토·후원자) |
| 활동 리포트 · 신호등 | 나눔 리포트 · 성장 단계 |
| (없음) | 자립 리포트 (선교사 월간 매출·자립도·기도제목) |
| (없음) | 캠프 · 순환 기금 관리 |

### 이미 만들어진 화면 (WMTO Connect, PWA)

- 회원 앱: 홈, 모임 일정·출석, 멘토링 기록, 자립 리포트, 매칭(요청·수락), 리퍼럴, 감사 편지, 성장 단계, 아카데미(영상), 프로필(언어 변경 포함), 더보기
- 관리자: 회원 승인, 일정, 매칭 배정, 성장 단계 변경, 스토리, 아카데미
- 아직 없음 (3단계 예정): 캠프·순환 기금 관리, 후원 추적, 온라인 결제·기부금 영수증
- 언어: 한국어, 영어
- 로그인: 이메일 링크(비밀번호 없음)

### WMTO에서 쓰는 용어

- 역할: 사업가 Mentor / 선교사 Partner / 후원자 Sponsor
- 사업가 단계: Seed → Sower → Harvester → Elder
- 선교사 단계: Ready → Launch → Growing → Self-Sustaining
- 사업가 기여 방식: 기술 전수, 경영 코칭, 판로 연결, 전문 자문
- 모임: 격주 온라인(60분), 월 1회 오프라인(챕터별), 월 1회 1:1 멘토링, 연 1회 글로벌 컨퍼런스

## 2. 분석 요청

BNI Connect를 직접 둘러보면서 아래를 정리해 주세요. **내가 접근할 수 있는 화면만** 보면 됩니다.

### A. 구조 파악
1. 상단·좌측 **메뉴 전체 구조**(메뉴 이름과 하위 메뉴)를 트리로 정리
2. 처음 로그인했을 때 보이는 **대시보드의 구성**(어떤 카드·위젯이 어떤 순서로, 각각 무엇을 보여 주는지)
3. 모바일 화면에서 메뉴와 레이아웃이 어떻게 달라지는지 (창 크기를 줄여서 확인)

### B. 핵심 기능별 상세 (있는 것만)
각 기능마다 **① 목적 ② 진입 경로 ③ 입력 항목(필수/선택, 선택지) ④ 저장 후 화면·알림 ⑤ 누가 볼 수 있는지**를 적어 주세요.

- 리퍼럴 주고받기 (슬립 작성, 상태 변화, 감사·완료 처리)
- 1:1 미팅 기록, 방문자(게스트) 초대·관리
- 감사(TYFCB 등) 기록
- 회원 검색·회원 프로필(어떤 항목을 보여 주는지, 공개 범위)
- 모임·행사 일정, 출석, 참석 확인
- 교육 콘텐츠·영상(있다면)
- 알림, 메시지, 공지
- 리포트·점수·신호등(어떤 지표를 어떻게 계산·표시하는지, 보이는 범위)
- 챕터·지역 구조, 관리자(챕터 임원) 전용 화면

### C. 사용성 관찰
1. 처음 쓰는 사람이 **가장 먼저 해야 하는 일**이 어떻게 안내되는가 (온보딩, 빈 화면 문구)
2. 반복해서 쓰는 동작이 **몇 번 클릭**으로 끝나는가 (예: 리퍼럴 보내기)
3. 입력 부담을 줄이는 장치(자동완성, 기본값, 최근 항목, 알림 유도 등)
4. 불편하거나 복잡해 보이는 부분
5. 참여를 **독려하는 방식**(배지, 순위, 리마인더, 문구)과 그것이 WMTO의 "경쟁이 아닌 격려" 원칙과 맞는지

### D. WMTO 관점의 비교
위 1장의 "이미 만들어진 화면"과 BNI Connect를 비교해서:
1. **WMTO에 이미 있고 BNI와 비슷한 것** — 그대로 두어도 되는 것
2. **BNI에는 있는데 WMTO에 빠진 것** — 가져오면 좋은 것 (우선순위 높음/중간/낮음)
3. **가져오면 안 되는 것** — 경쟁·순위·돈 중심이라 WMTO 가치와 충돌하는 것, 이유와 함께
4. **WMTO에 맞게 바꿔서 가져올 것** — BNI 기능 → WMTO 버전 제안 (예: "리퍼럴 슬립" → "선교사 ↔ 사업가 매칭 요청", 구체적인 화면과 입력 항목까지)
5. 선교사(Partner)·후원자(Sponsor)는 BNI에 없는 역할이므로, 이 역할의 **첫 화면에 무엇이 있으면 좋을지** BNI의 패턴을 참고해 제안

## 3. 후보 아이디어 (검토 대상)

다음은 BNI를 보고 생각해 둔 후보입니다. 각각 타당한지 의견을 주세요.

1. 첫 화면에 "오늘 할 일" 한 가지만 크게 보여 주기 (예: 이번 달 자립 리포트 쓰기, 대기 중인 매칭 요청 확인)
2. 모임 직전 알림과 한 번에 누르는 출석 체크
3. 리퍼럴·감사에 "이 일로 누가 도움을 받았는지" 짧은 문장으로 남기기
4. 사업가의 활동을 **단계 이름과 이야기**로 보여 주는 "나눔 리포트" (월간 요약)
5. 새 회원을 위한 첫 30일 안내(오리엔테이션 체크리스트)
6. 챕터 단위 공지와 모임 후기
7. 방문자(참관자) 초대 링크와 참관 후 후속 안내

## 4. 결과 형식 (이 형식으로 답해 주세요)

한국어로, 아래 순서와 제목을 지켜 마크다운으로 작성하세요. 개인정보는 넣지 마세요.

```
# BNI Connect 분석 결과

## 1. 메뉴·화면 구조 (트리)
## 2. 대시보드 구성
## 3. 기능별 상세 (기능마다 ①~⑤)
## 4. 사용성 관찰
## 5. 확인하지 못한 화면 / 권한 때문에 못 본 것
## 6. WMTO 비교
  ### 6-1. 이미 있고 비슷한 것
  ### 6-2. 빠진 것 (우선순위 표시)
  ### 6-3. 가져오면 안 되는 것과 이유
  ### 6-4. WMTO 버전으로 바꿔 가져올 것 (화면·입력 항목 포함)
  ### 6-5. 선교사·후원자 첫 화면 제안
## 7. 3장 후보 아이디어에 대한 의견 (번호별 찬성/보류/반대와 이유)
## 8. 가장 먼저 반영하면 좋은 5가지
## 9. 확인표 (0-1장의 표)
```

각 항목은 **관찰한 사실**과 **내 추측·제안**을 구분해서 쓰세요. (예: "확인함 / 추정")
