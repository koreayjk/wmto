# 12. 크롬 Claude에게 보낼 요청서: BNI Connect 사업가(멤버) 화면 기능 조사

> ⚠️ **내부 참고 자료.** 다른 서비스를 조사·분석한 내용을 담고 있어 공개 저장소에 두지 않습니다(저장소를 공개로 바꾸기 전에 이 문서를 옮기거나 삭제). 서비스 화면·문구·점수 숫자를 그대로 쓰지 않는 것이 원칙입니다(docs/10).


> 아래 "복사해서 붙여넣기" 부분을 크롬의 Claude 사이드 패널에 그대로 붙여 넣으세요. 이미 로그인된 `bniconnectglobal.com/web/dashboard` 탭에서 실행해야 합니다.

## 사용 방법
1. 크롬에서 BNI Connect에 **본인 계정으로 로그인**한 상태로 대시보드 탭을 엽니다. (로그인이 필요한 화면이라 이 세션의 Claude는 접속할 수 없습니다. 비밀번호·인증번호는 어디에도 입력하거나 공유하지 마세요.)
2. 아래 요청서를 크롬 Claude에 붙여 넣습니다.
3. 크롬 Claude가 만든 결과(마크다운)와 스크린샷 폴더를 이 대화에 올려 주세요(파일 첨부 또는 붙여넣기). 스크린샷을 그림으로 보고 이어서 우리 쪽 기능 설계에 반영하겠습니다.

## 복사해서 붙여넣기 (여기부터)

당신은 내가 쓰는 BNI Connect 웹 화면(회원 계정, 이미 로그인됨)을 **읽기 전용**으로 둘러보고, **사업가(멤버) 입장에서 쓰는 기능**을 정리하는 조사원입니다.

### 목적
우리는 크리스천 사업가 네트워크 앱을 만들고 있습니다. BNI의 문구·디자인·점수 숫자를 베끼려는 것이 아니라, **어떤 기능 영역이 있고 어떻게 흘러가는지**(기능 아이디어)만 파악해서 우리만의 방식으로 새로 설계하려는 것입니다.

### 꼭 지킬 규칙
- **읽기만 하세요.** 저장, 제출, 삭제, 결제, 초대 보내기, 메시지 발송, 설정 변경 같은 버튼은 누르지 마세요. 입력 칸에 값을 넣어 제출하지 마세요.
- 개인정보는 기록하지 마세요: 다른 회원의 이름·연락처·사진·이메일, 금액·매출 등 구체 수치는 적지 말고 `[이름]`, `[금액]`처럼 가립니다. 스크린샷을 저장할 때도 가능하면 개인정보 부분을 가리거나 개인정보가 없는 화면만 찍으세요.
- 문구를 그대로 베끼지 말고 **기능을 내 말로 요약**하세요. (화면 이름은 원문 그대로 적어도 됩니다.)
- 로그인 정보, 토큰, 주소창의 인증 파라미터는 기록하지 마세요.
- 막히거나 권한이 없어 보이는 화면은 "접근 불가"라고만 적고 넘어가세요.

### 해야 할 일
왼쪽 아이콘 메뉴(홈, 지구본, 톱니바퀴, 문서, 공유 등)와 상단 메뉴("멤버 모듈" 등), 대시보드의 카드·탭·정보(i) 아이콘 설명을 하나씩 열어 보면서, 각 화면마다 아래를 기록합니다.

1. **화면 이름과 경로**(주소에서 `/web/...` 부분만)
2. **무엇을 하는 화면인가**(한두 문장)
3. **보이는 항목·지표·필터·기간 탭**(예: 최근 6개월/12개월/평생)
4. **사용자가 할 수 있는 동작**(조회만인지, 입력 양식이 있는지. 양식이면 입력 항목 이름만 나열하고 제출은 하지 않기)
5. **다른 화면과의 연결**(어디서 와서 어디로 이어지는지)
6. **우리 앱에 적용할 만한 아이디어**와 **그대로 하면 안 될 부분(복제 위험)** 한 줄씩

특히 다음 영역을 빠짐없이 확인해 주세요:
- 대시보드 지표(보낸/받은 소개, 감사 금액, 1:1 미팅 횟수, 손님 초대, 출석, 교육 이수 등)와 기간 전환, 정보(i) 설명
- 소개(리퍼럴) 보내기·받기 흐름과 진행 상태
- 감사 기록(감사장) 흐름
- 1:1 미팅 기록 양식과 증빙(사진) 방식, 점수 반영 방식 설명
- 손님(방문자) 초대·관리 흐름
- 출석·대리 출석·결석 처리
- 교육/학습(이수 기록) 화면
- 점수·등급·갱신(리뉴얼) 관련 화면과 안내 문구의 요지
- 챕터(모임) 정보, 멤버 디렉터리, 검색, 프로필 편집 항목
- 직책/임원 관련 기능(보이는 범위만)
- 알림, 메시지, 도움말
- 모바일 앱·QR·공유 같은 부가 기능
- 결제/회비/갱신 결제 화면이 보이면 **구성 항목만**(금액은 가림)

### 결과물 형식
1. **`bni-survey.md`** — 화면별로 위 6개 항목을 정리한 마크다운. 맨 위에 "전체 메뉴 지도"(트리)와 "기능 영역 체크리스트"(위 목록 중 확인한 것/못 한 것)를 넣어 주세요.
2. **스크린샷** — 화면마다 1장(개인정보 가림). 파일명은 `01-dashboard.png`, `02-referrals.png`처럼 번호와 화면 이름으로 붙여 하나의 폴더에 저장하고, `bni-survey.md`에서 파일명으로 참조해 주세요.
3. 마지막에 **"우리 앱에 우선 적용하면 좋을 것 TOP 10"**과 **"복제로 보일 위험이 있어 피해야 할 것"** 목록을 적어 주세요.

시작하기 전에 조사할 화면 목록을 먼저 보여 주고, 내가 "진행"이라고 하면 조사를 시작하세요.

## 참고: 이 조사의 한계와 주의
- **이 세션의 Claude는 BNI Connect에 직접 들어갈 수 없습니다.** 로그인이 필요하고, 도움말 센터(support.bniconnect.com)도 자동 접속을 막아 두었습니다.
- 회원 약관(멤버십 동의서)에 **자료·시스템 화면의 복제·재사용 제한**이 있을 수 있습니다. 화면 캡처와 요약은 우리 설계 참고용으로만 쓰고, **외부에 공개하거나 그대로 옮기지 않습니다.** 불안하면 약관의 해당 조항을 먼저 확인하세요(docs/09 법적 체크리스트 참고).
- 스크린샷에는 본인과 다른 회원의 정보가 있을 수 있으니, 저장소(깃)에 올리지 말고 이 대화에 직접 첨부해 주세요.
