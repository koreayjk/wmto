# 15. 개인정보 처리 현황표 (법률 검토용 초안)

> ⚠️ 변호사·개인정보 담당자 검토용 **초안**입니다. 앱의 실제 표·화면을 기준으로 정리했고, 보유 기간·법적 근거 열은 **제안**이며 확정이 아닙니다. 처리방침·이용약관 작성의 재료로 쓰세요.
> 내부 자료: 저장소를 공개로 바꾸기 전에 옮기거나 지우세요.

## 2. 특히 주의가 필요한 항목
1. **종교 관련 정보**(섬기는 교회, 신앙 이야기, 선교 권한 신청 동기): 개인정보 보호법상 **민감정보로 볼 가능성** → 별도 동의, 수집 최소화, 공개 범위 설명 필요. 선택 입력으로만 받고 있음.
2. **제3자 정보**(소개한 고객, 초대한 손님의 이름·연락처): 정보주체가 아닌 회원이 입력함 → 입력 시 "당사자의 동의 또는 이에 준하는 근거" 안내 문구, 최소 입력(연락처 선택), 보유 기간 단축, 열람·삭제 요청 대응 필요. 앱은 연락처 입력을 선택으로 두고 소그룹 게시판에는 고객 연락처를 적지 말라고 안내함.
3. **사진**: 증명사진은 공개 버킷(앱 내 노출), 1:1 증빙 사진은 비공개 버킷에 두 사람 동의 시에만. 보관 기간·삭제 절차 필요.
4. **건강 정보로 읽힐 수 있는 결석 사유**: 사유 선택지에 '몸이 좋지 않아요'가 있음. 텐트장에게는 사유 자체를 보여 주지 않고 알림만 줌(현재 구현은 이름·행사 제목만). 사유 저장 기간을 짧게.
5. **국외 이전**: Supabase(미국 오리건), Vercel, 메일 발송(Resend)이 국외 서비스 → 처리방침에 이전 국가·항목·시기·방법·보유 기간·거부 방법 고지(개인정보 보호법). 서울/도쿄 이전 계획이 있다면 함께 반영.
6. **회원 간 공개 범위**: 같은 텐트 회원은 서로의 이름·업종·사진·프로필 일부를 봄. 점수는 본인과 텐트장·운영진만(공개 범위는 미결정 항목).
7. **마케팅 이용 금지**: 회원 명단·연락처를 소개·관계 구축 외 용도로 쓰지 않는다는 약관 조항 필요.
8. **메일 알림**: 동의 기반(기본 꺼짐), 하루 한 번 요약, 언제든 끄기. 처리방침에 발송 항목·위탁(발송 서비스) 명시.

## 3. 정보주체 권리 대응 (구현 현황)
| 권리 | 구현 |
|---|---|
| 열람·내려받기 | 내 정보 권리 화면: 내 데이터 JSON 내려받기 |
| 정정 | 내 정보 화면에서 직접 수정(업종은 승인제) |
| 삭제·탈퇴 | 탈퇴 요청 → 운영진이 계정·정보 정리(자동 삭제 아님, 법령 보관분 분리) |
| 동의 철회 | 메일 알림 끄기, 사진 동의는 1:1 건별 |
| 이의 신청 | 갱신 심사에서 회원 의견 남기기 |

## 4. 검토 요청 사항(질문 목록)
- 종교 관련 정보를 선택 입력으로 받을 때의 동의 방식과 문구
- 제3자(고객·손님) 정보를 회원이 입력하는 구조의 책임 분담과 안내 문구
- 보유 기간 확정, 법령상 보관 의무(회비, 후원금)와의 충돌 정리
- 국외 이전 고지·동의 방식(Supabase 오리건·Vercel·Resend)
- 점수 기반 갱신 심사의 설명 의무·이의 절차(자동화된 결정에 준하는지)
- 만 14세 미만 가입 제외: 신청서 동의 문구에 "만 14세 이상" 확인을 포함함(생년월일은 수집하지 않음)
- 개인정보 보호책임자 지정과 연락처, 처리방침 개정 이력
