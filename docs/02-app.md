# WMTO 회원 앱 개발 브리프 (WMTO Connect, 가칭)

> 반드시 `00-wmto-overview.md`를 먼저 읽으세요. 용어·코드 값·단계는 그 문서를 따릅니다.
> 이 앱은 홈페이지(`01-website.md`)에서 만든 **같은 DB를 그대로 이어서** 씁니다. 기존 테이블(`members`, `mentor_profiles`, `partner_profiles`, `sponsor_profiles`, `applications`, `events`, `stories`)을 새로 만들지 말고 확장하세요.
> 이 문서는 홈페이지 런칭 후 개발합니다.

---

## 1. 앱 컨셉

- BNI Connect가 "리퍼럴(돈 되는 소개)"을 기록한다면, WMTO Connect는 **"나눔과 자립의 과정"**을 기록
- 경쟁이 아니라 격려: 활동 점수는 색깔 순위가 아니라 성장 단계 이름으로 표시
- 홈페이지 신청자(`members.status = applicant`)가 승인되면 `active`로 바뀌고, 앱 로그인 계정(`auth_user_id`)이 연결됨

## 2. BNI Connect → WMTO Connect 대응

| BNI Connect | WMTO Connect |
|---|---|
| 회원 프로필 | 역할별 프로필 (사업가·선교사·후원자) |
| 1:1 미팅 기록 | 멘토링 기록 |
| 리퍼럴 슬립 | 매칭 요청 · 사업가 간 소개 |
| 감사 슬립 (TYFCB) | 감사 편지 (선교사 → 멘토·후원자) |
| 활동 리포트 · 신호등 | 나눔 리포트 · 성장 단계 |
| — | 자립 리포트 (WMTO 고유) |
| — | 캠프 · 순환 기금 관리 (WMTO 고유) |

## 3. 역할별 메인 화면

### 사업가 (Mentor)
- 내 멘티 선교사 목록과 자립 진행률
- 이번 달 멘토링 일정 · 기록 작성
- 매칭 요청함 (나를 필요로 하는 선교사)
- 내 성장 단계 (Seed → Elder)와 활동 점수
- 사업가 간 리퍼럴 보내기·받기
- 캠프 강사 지원

### 선교사 (Partner)
- 내 자립 단계 (Ready → Self-Sustaining) 진행 바
- 담당 멘토와 대화 · 다음 멘토링 일정
- 월간 자립 리포트 작성 (매출, 어려움, 기도제목)
- 캠프 신청 · 순환 기금 신청과 상환 현황
- 감사 편지 쓰기

### 후원자 (Sponsor)
- 내가 후원한 선교사 소식 피드
- 내 후원금이 흘러간 경로 (순환 기금 추적)
- 후원 내역 · 기부금 영수증

### 공통
- 격주 온라인 모임 일정 · Zoom 바로가기 · 지난 강의 다시보기
- 챕터 소식, 선교 현장 보고
- 아카데미 (강의 영상 라이브러리)
- 회원 디렉토리 (업종·지역·기여 방식으로 검색) — 사업가·선교사만, 공개 범위 설정 가능

### 관리자
- 신청 승인 → 회원 활성화 · 계정 초대
- 매칭 배정, 성장 단계 승급 승인
- 캠프·기금 관리, 공지 발송

## 4. 활동 점수

- 사업가: 모임 출석, 멘토링 횟수, 강의 참여, 매칭 건수, 신규 회원 초대
- 선교사: 모임 출석, 월간 자립 리포트 제출, 멘토링 참여, 사업 진행 단계
- 승급은 점수 자동 계산 + 관리자 승인

## 5. 추가 테이블 (기존 테이블과 `member_id`로 연결)

| 테이블 | 용도 |
|---|---|
| `chapters` | 챕터(권역) 정보 |
| `attendance` | 모임 출석 (`events`와 연결) |
| `matchings` | 사업가 ↔ 선교사 매칭 (기여 방식 포함) |
| `mentoring_logs` | 멘토링 기록 (일시, 시간, 내용) |
| `referrals` | 사업가 간 고객 소개 |
| `thanks_letters` | 감사 편지 |
| `self_reports` | 선교사 월간 자립 리포트 (매출, 자립도, 어려움, 기도제목) |
| `stage_history` | 성장 단계 변경 이력 |
| `camps` / `camp_enrollments` | 캠프 회차, 참가자·강사 등록 |
| `fund_loans` / `fund_repayments` | 순환 기금 대여·상환 |
| `donations` | 후원 내역 (방식 코드, 대상 선교사, 금액) |
| `academy_videos` | 아카데미 강의 |

- 코드 값(역할, 단계, 기여 방식, 후원 방식, 슬립 종류)은 `00-wmto-overview.md` 기준 enum 사용
- RLS: 선교사 자립 리포트는 본인·담당 멘토·관리자만, 후원자는 자신이 후원한 선교사 소식만 조회

## 6. 개발 단계

1. **1단계**: 로그인·프로필, 모임 일정·출석, 멘토링 기록, 자립 리포트
2. **2단계**: 매칭, 리퍼럴, 감사 편지, 활동 점수·성장 단계, 아카데미
3. **3단계**: 캠프·기금 관리, 후원 추적, 온라인 결제·기부금 영수증

## 7. 화상 모임·강의

- **1단계 (현재 결정)**: Zoom 유료 계정 사용. 앱·홈페이지에는 `events.zoom_url`로 바로가기만 제공
- **확장 시 (회원 100명+, 정기 강의·녹화 활발)**: BigBlueButton(BBB) 오픈소스로 전환 검토
  - 관리형 BBB 호스팅 → 이후 자체 서버(Hetzner 싱가포르 전용 vCPU, 16GB 이상) 순서
  - BBB API로 앱 안에서 회의 생성·입장, 녹화본을 `academy_videos`로 자동 연결
- 지금 설계 시 주의: 회의 링크를 Zoom에 묶지 말고 `meeting_provider`(`zoom`/`bbb`) + `meeting_url` 구조로 두어 나중에 교체 쉽게

## 8. 미정 사항

- 앱 형태: 웹앱(PWA)으로 시작할지, 네이티브 앱으로 갈지
- 결제 수단(국가별), 기부금 영수증 발행 주체
- 다국어: 한국어 → 영어 순
