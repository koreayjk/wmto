# 13. 참고 자료 → 우리 설계 매핑 (우리 것으로 만들기)

> ⚠️ **내부 참고 자료.** 다른 서비스를 정리한 자료(`BNI_CONNECT_REFERENCE.md`, 사용자 제공)를 바탕으로 한 문서입니다. 공개 저장소에 두지 않습니다.
> 원칙(docs/10): **기능 아이디어만** 가져온다. 이름·용어·점수 배점·색 등급 이름·화면 구성·문구는 가져오지 않는다. 아래 "우리 쪽" 열이 우리 설계이며, "참고 자료" 열의 용어는 대응 관계를 보기 위한 것일 뿐 앱·문서·화면에 쓰지 않는다.

## 1. 모듈 대응

| 주간 모임 도구 | 아젠다·스크립트·슬라이드·스피커 배정·뉴스레터 | 미구현. 우리 방식(기도·말씀·간증 순서, 발표자 순번)으로 별도 설계 필요 | 후보 |

| 타 지역 연결 | 다른 챕터 회원과 소개·1:1 | 텐트 간 소개·1:1(같은 나라/온라인 먼저) | 후보 |

| 알림·메일 | 시스템 메일 템플릿, 그룹 알림 빈도 | 앱 안 알림(완료). 메일·푸시, 알림 빈도 설정은 미구현 | 일부 |
| 결제 | 구독형 가입비·갱신비 | 법인·결제 대행사 확정 후 | 보류 |
| 공개 API | 제공하지 않음(요청만 있음) | 필요 시 나중에 | — |

## 2. 우리가 일부러 다르게 하는 것
1. **선교 권한 층**: 사업 네트워크가 본체, 선교는 신청·승인 또는 지정으로 여는 층.
2. **점수의 목적**: 순위·색 낙인이 아니라 다음 걸음 안내. 단계 이름은 말뚝·기둥·천막·등불, 색 신호등 없음.
3. **소개의 대가 금지**: 거래 금액·수수료 기록을 점수에 넣지 않는다(정책 확정 전까지 감사 금액 기록 보류).
4. **개인정보**: 1:1 사진은 두 사람 동의, 공개 노출은 기본 꺼짐, 메일 비노출.
5. **갱신은 사람이 결정**: 점수는 참고, 말뚝도 개선 계획과 지원 기간을 거친다.

## 3. 법적으로 피해야 할 것(체크)
- 용어: 챕터→텐트, 전표→기록, 리더십 팀→텐트 섬김이, 트래픽 라이트→성장 단계 등으로 이미 대체. 새 기능에도 원문 용어(PALMS, TYFCB, CEU, 1-2-1, 트래픽 라이트, 프레지던트/VP 등)를 쓰지 않는다.
- 배점·임계값: 우리 숫자 사용(docs/10), 임의 조정 가능하게 상수로 분리.
- 화면: 구성·배색·아이콘을 따라 그리지 않는다.
- 약관: 서비스 이용약관의 복제 금지 조항을 확인(미확인).

## 4. 다음 작업 우선순위(제안)
1. ✅ 텐트장 대시보드 (이번): 건강 지표, 회원 현황, 비어 있는 업종, 다음 걸음 안내

## 6. 내부 화면 조사(`bni-survey.md`, 1차) 반영 현황
조사한 화면에서 **기능 아이디어만** 가져와 우리 방식으로 만든 것(0023):

| 조사에서 본 기능 | 우리 쪽 | 비고 |
|---|---|---|
| 대시보드 카드 + 카드별 "기록하기·보기" | 홈의 **내 활동 한눈에**: 9개 숫자 + 바로 가기, 기간 탭(90일·1년·전체) | 카드 이름·배치·색은 우리 것 |
| 소개 진행 상태 파이프라인, 성사 → 감사 연결 | 상태: 전달됨·연락함·**성사**·성사되지 않음·마무리. 성사되면 받은 사람이 **감사 남기기**, 소개한 분에게 알림 | 금액 기록 없음(대가 없는 소개 원칙) |
| 소개 품질 신호(온도, 미리 연결) | **고객의 관심 3단계**(알아보는 중/곧 필요/바로 필요) + "미리 연락해 두었어요" | 5단계 색 막대 쓰지 않음 |
| 방문 유형(손님·게스트·대리) 한 양식 | 초대 유형 **손님 / 참관 / 대신 나옴**(대신하는 회원 지정). 손님만 점수에 반영 | 명칭 다름 |
| 학습 종류 × 수량 표 | **학습 기록**: 말씀 묵상, 제자훈련, 비즈니스 강의, 책 읽기(단위 1~2). 아카데미 이수와 함께 '배움' 점수에 반영 | 교육 과정·도서 목록 쓰지 않음 |
| 프로필 완성도와 빠진 항목 안내 | **프로필 완성도** + 소개·키워드·사업 햇수·웹사이트·섬기는 교회·신앙 한 줄·선교 마음 | 질문 세트는 우리 것 |
| 감사(점수) | 성장 지표에 **감사** 항목(성사된 소개에 감사 남기기) 추가: 7개 항목 100점 환산 | 배점 우리 것 |

아직 안 한 것(조사 후보): 받은 소개 상세 추적지(고객 연락처 열 보기), 멤버 키워드 검색, 이벤트와 학습 연동, 개인 기록 리포트 인쇄, 모임 단체 메시지·메시지함, 추천사 요청, 소그룹.
