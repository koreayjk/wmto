# BNI Connect 분석 결과

- 조사일: 2026-10-23 / 대상: 일반 멤버 계정(한국, 챕터 소속)
- 표기: **[확인]** 직접 본 사실, **[추정]** 제 추측·제안
- 원칙: 읽기만 했습니다. 저장·제출·전송·그룹 참여는 하지 않았고, 다른 회원의 실명·연락처·금액은 적지 않았습니다.
- 화면 폭: PC 1534px, 모바일 420px

## 1. 메뉴·화면 구조 (트리)

BNI Connect는 **새 UI**(카드형, 모바일 친화)와 **클래식 UI**(상단 메뉴 + 우측 업데이트 패널)가 함께 있습니다. [확인] 새 화면 헤더의 ⇄ 아이콘, 클래식의 "Switch to new dashboard", 프로필의 "Edit in Legacy"로 오갑니다. 기능에 따라 열리는 UI가 다르고, 일부 링크는 새 탭으로 열립니다.

**새 UI 좌측 사이드바** [확인]

- 홈 (대시보드)
- 네트워크
  - 그룹
  - 인맥
  - 추천
  - 사진 갤러리
- 활동
  - 챕터
- 리포트
  - 챕터
- Shortcuts
  - 멤버 모듈
  - 내 인맥
  - 챕터
- 도움 (외부 지원 사이트)
- Info (사용약관, 개인정보 규정)

**새 UI 헤더** [확인]

- 벨 아이콘: 알림이 아니라 메시지 메뉴(받은 메일 / 전송 / 작성)
- 프로필 드롭다운: 내 계정 / 계정(Portal) / 로그아웃
- ⇄ 아이콘: 클래식 화면 전환
- 상단 칩: 챕터명, 갱신일 버튼, 지역 홈페이지 링크, 등급 배지

**클래식 UI** [확인]

- 상단 메뉴: 홈 / 네트워크 / 활동 / 리포트
- 아이콘: 메시지, 인물 검색, 인쇄, 도움, 번역
- 국가 > 지역 > 챕터 선택 드롭다운
- 우측 패널: 업데이트 피드, 향후 이벤트, 서류, 안 읽은 메시지

**활동 > 챕터 (클래식)** [확인]

- 비지터 관리: Visitor Registration Portal
- 미팅 관리: PALMS 요약 보기
- 목표 관리: 챕터 목표 보기
- 이메일 작성: 내 챕터 전체 / 비지터 초대장 / 비지터에게

**리포트 > 챕터 (클래식, 20종)** [확인]

- 멤버: 멤버 트레이닝, 챕터 멤버 현황, 멤버 참가비 납부일, 멤버 디테일, 멤버 참가 기간
- 미팅·출석: 미팅 노트, 요약 PALMS, 개인 PALMS, PALMS 출석, 결석, 발표자
- 챕터 상태: 챕터 내 없는 전문분야, 챕터 트래픽 라이트
- 임원: 지역 리더십, 가디언, 부의장, 부의장 누적
- 비지터: 챕터 비지터, 비지터 등록, 가망 비지터 결석

**이벤트** [확인]

- 다가올 이벤트 보기(표: 이벤트명, 시작 시간, 장소, 검색)
- 내셔널 이벤트 상세(등록신청하기 버튼)

## 2. 대시보드 구성 [확인]

**위에서 아래 순서**

1. 인사말("Hello 이름"), 검색 아이콘, 챕터 칩, 갱신 버튼, 지역 홈페이지 버튼, 등급 배지
2. **준 리퍼럴 누적 그래프**(왼쪽, 확대 아이콘)와 기간 토글(최근 6개월 / 12개월 / 평생)
3. **지표 카드 7장**(오른쪽, 그래프와 나란히)
   - 준 감사장(TYFCB): 금액, [Submit TYFCB / Review]
   - 받은 리퍼럴: 건수, [Track Online]
   - 준 리퍼럴: 건수, [Submit / Review]
   - 받은 감사장(TYFCB): 금액만 표시
   - 비지터: 건수, [Visitor Portal]
   - 교육학점(CEU): 합계, [Submit / Review]
   - 원투원: 건수, [Submit / Review]
4. **리포트 바로가기 3개**: 주간 미팅 활동 인쇄 / 받은 리퍼럴 리포트 / 자신의 참가현황 리포트
5. **Profile Optimisation**: 완성도 % 게이지, "이 항목을 채우세요" 목록, [Update]
6. **Upcoming Meetings and Events**: 이벤트·챕터 미팅 카드(날짜, 이름, 장소, [View Details]), [See More]

**모바일(420px)** [확인]

- 헤더가 햄버거(☰), 로고, 벨, 프로필로 바뀝니다.
- 사이드바는 아코디언 드로어입니다(홈, 네트워크▾, 활동▾, 리포트▾, Shortcuts▾, 도움, Info▾).
- 카드는 1~2열로 쌓이고, 칩과 버튼은 가로 전체 폭이 됩니다.
- 우하단 채팅(챗봇) 플로팅 버튼이 PC·모바일 모두 있습니다. 도메인상 AI 챗봇으로 [추정]됩니다.

## 3. 기능별 상세

### 3-1. 리퍼럴 슬립 (준 리퍼럴 Submit) [확인]

- ① 목적: 챕터 동료에게 사업 기회를 건넨 것을 기록
- ② 진입: 대시보드 "준 리퍼럴" 카드 [Submit] → 모달
- ③ 입력 항목
  - 날짜, 보낸 사람(자동)
  - 받는 사람(필수): 내 챕터 멤버 드롭다운 또는 [다른 챕터 검색]
  - 리퍼럴 이름(필수)
  - 리퍼럴 타입(필수): T1 / T2 (기본 T2)
  - 상태(필수, 체크박스): 명함 전달 / 상대방에게 전화한다고 했음
  - 주소, 전화(필수), 이메일, 코멘트
  - 우측에 "얼마나 핫한가요?" 4단계 색상 척도
  - 버튼: 저장하기 & 새로 만들기 / 제출 / 닫기
- ④ 저장 후: 제출하지 않아 확인하지 못함
- ⑤ 누가 보나: 받은 사람, 보낸 사람, 챕터 임원(PALMS) [추정]

**리뷰 리포트**: 기간(시작/종료일) 선택 → 표(날짜, 수신, 리퍼럴, 내부/외부, 상태, 전화, 이메일, 코멘트, 리퍼럴 기간, 추적시트 상태, PALMS 현황, 합계). 버튼: 장표 수정/삭제, 파일로 저장, 프린트. 제출된 PALMS 리포트는 소속 챕터 부의장에게 요청해야 수정 가능 상태가 됩니다.

**리퍼럴 추적지(Track Online)**: 시작일, 종료일, 현황 필터 + Go. 현황 값 7가지: Not Contacted Yet / Contacted / Got The Business / Did Not Get The Business / No Response / Not a Good Fit / Confidential. 표: 이름, 이메일, 전화, 날짜, 현황, TYFCB, 옵션(수정).

### 3-2. 감사장 TYFCB [확인]

- ① 목적: 받은 리퍼럴로 실제 사업이 성사됐음을 기록
- ② 진입: [Submit TYFCB]
- ③ 입력: 챕터·날짜(자동), 감사할 대상(필수), 감사장 금액(필수, 현지 통화), 비즈니스 타입(필수: 신규/재구매), 리퍼럴 타입(필수: T1/T2/T3+), 코멘트. 버튼: 저장하기 & 새로 만들기 / 제출 / 닫기
- ④⑤: 제출하지 않음. 받은 감사장 카드에는 금액 합계만 보임

### 3-3. 원투원(1:1) [확인]

- ① 목적: 멤버 간 1:1 만남 기록
- ② 진입: [Submit]
- ③ 입력: 만난 사람(필수), 초대자(필수), 장소(필수), 대화 주제(필수), 날짜(필수, 기본 오늘). 버튼: 저장하기 & 새로 만들기 / 제출 / 닫기
- 특징: 결과 평가나 다음 약속 같은 후속 항목이 없음

### 3-4. 교육학점 CEU [확인]

- 코스 표(코스명, 학점/코스, 획득 수량 입력, 지난주 획득 합계)와 총계. 코스는 1~5점으로 구성(미니 워크숍, 팟캐스트, 멤버 석세스 프로그램, 리더십 팀 트레이닝, 멤버스킬 과정, 외부 네트워킹 워크숍, 공식 도서).
- 버튼: 제출 / 닫기

### 3-5. 비지터(게스트) 등록 [확인]

- 진입: [Visitor Portal] → **새 탭**의 "비지터 등록 포털" → 카드 "비지터 등록 추가"
- 모드: 다른 사람을 제 챕터에 방문하게 등록 / 다른 챕터를 방문하려면 나를 등록
- 입력: 등록 챕터, 방문 날짜, 칭호, 이름(국문·영문), 접미사, 이메일, 전화, 회사명, 주소 필드, 카테고리, 비지터 유형(Visitor/Guest/Substitute), "시스템이 대신 초대장을 보내도록 허용" 동의 체크
- 버튼: 양식 초기화 / 등록 저장

### 3-6. 멤버 프로필 [확인]

- 구성: 사진, 이름, 가입 기간, 지역·챕터, 완성도(%), 인맥 수, 추천의 말, 개인 상세내역, 내 신상명세(Gains 프로필, Tops 프로필 등), Professional Details, 트레이닝 기록, 그룹, 사진
- 빈 항목은 "Complete your…" 안내와 퍼센트로 입력을 유도. 공개 범위 설정은 못 봄

### 3-7. 인물 검색 [확인]

- 키워드 한 칸 + 고급 검색(키워드, 이름, 회사명, 국가, 도시, 주, 직종)
- 안내문: 키워드, 이름, 직종, 제품·서비스, 회사명, 주소, 도시, 주, 이메일, 전화가 검색 대상

### 3-8. 인맥 / 추천사 [확인]

- 인맥 첫 화면: 내 인맥 / 보낸 요청 / 받은 요청 3카드, [인맥 추가]
- 내 인맥: 검색 + 카드 격자(사진, 이름, 직종 태그, 챕터)
- 카드 팝업: 직종, 주소, 전화 + 버튼 4개(View Profile / Give Testimonial / Ask Testimonial / 메시지 보내기)
- 추천사 첫 화면: 받은 / 준 / 요청 3카드, [My Connections]
- 추천사 쓰기 폼: **필수 1칸(본문)**, 제출·취소

### 3-9. 그룹 [확인]

- 목록: 카드(대표 이미지, 제목, 개설일, 설명, 게시글·멤버 수, 개설자, 최근 게시일), 검색, 필터(제목·설명 / 주제 / 생성인), [내 그룹], [그룹 추가], [그룹 참여하기]
- 그룹 추가 폼: 그룹 이름, 그룹 종류, Access Type, 언어, 인맥 초대하기, 그룹 설명. 만들 수 있는 그룹 수에 한도 있음
- 상세·게시글은 "참여하기"가 즉시 참여 버튼이라 누르지 않아 못 봄

### 3-10. 메시지, 업데이트 피드 [확인]

- 받은 편지함: 보낸 사람, 주제, 날짜 표, 선택 삭제, 작성
- 작성: 받을 사람(다중), 주제, Body, 보내기/취소
- 업데이트 피드: "OO가 프로필 메시지/사진을 업데이트했습니다", "OO가 OO를 추천했습니다"

### 3-11. 이벤트·교육 [확인]

- 이벤트 상세: 종류, 이름, 설명, 개최국, 담당자, 장소(온라인/오프라인), 시간대, 시작·종료, 멤버/비멤버 참가비, 등록자 수, 상세 안내, [등록신청하기]
- 교육과정이 이벤트로 올라오며 본문에 교육 점수, 신청 마감, 최소 모집 인원, 이수 조건(운영 시간의 2/3 이상 참여) 같은 운영 규칙이 들어 있음
- 교육 영상 콘텐츠는 못 찾음

### 3-12. 챕터 목표 / PALMS / 이메일 (클래식) [확인]

- **챕터 목표 보기**: 시작월 선택 → 6개월 표. 상단 "장기 비전"·"미션 문구". 항목: 출석률, 1:1 미팅 수, CEU, 신규 멤버, 챕터 멤버 수, 리퍼럴 수, TYFCB. 항목마다 목표 / 실제 / 메카니즘 1·2(달성 방법 칸). 파일 저장·프린트
- **PALMS 요약**: "시작날짜 입력" + [리포트 보기]. 다른 멤버 데이터가 나올 것 같아 실행하지 않음
- **챕터 전체 이메일**: 발송 기능이 아니라 멤버 이메일 목록을 복사해 내 메일에 붙이는 화면

### 3-13. 개인 리포트 [확인]

- **주간 미팅 활동 인쇄(개인 미팅활동 시트)**: 기간, 양식/표 선택. 그 주 만난 1:1 상대와 비지터 목록(비지터 호스트에게 보고하라는 안내)
- **자신의 참가현황(개인 부의장 리포트)**: 주차별 행(출석, 준 T1/T2, 받은 T1/T2, 비지터, 1:1, 감사장 금액, CEU), 약어 범례, 파일 저장·프린트

### 3-14. 점수·신호등 [확인/한계]

- 챕터 트래픽 라이트 리포트는 월·연도를 고르는 입력까지만 보았고 결과 화면이 열리지 않았습니다. 지표 정의와 색 기준은 못 봤습니다.
- 대시보드에는 신호등이 없고 숫자 카드와 누적 그래프로 보여 줍니다.

## 4. 사용성 관찰

- **온보딩** [확인]: 튜토리얼은 못 봤고, 프로필 완성도 게이지와 "채울 항목" 목록이 전부. 번역이 덜 된 영어 문구가 섞여 있음(Profile Optimisation, Upcoming Meetings and Events, Submit, Review, Track Online)
- **클릭 수** [확인]: 리퍼럴 보내기는 Submit 1번 + 받는 사람 선택 + 필수 3~4개 입력 + 제출. 모달이라 화면 이동은 없지만 입력 항목이 많은 편
- **입력 부담을 줄이는 장치** [확인]: 챕터 멤버 드롭다운, 날짜 기본값, "저장하기 & 새로 만들기"(연속 입력), 핫 정도 색 척도, 프로필 완성도 %, 추천사의 1칸 폼
- **불편한 점** [확인]
  - 새 UI와 클래식 UI가 섞여 있고 새 탭으로 열리는 링크도 있음
  - 용어가 많음(T1/T2/T3+, PALMS, CEU, TYFCB)
  - 리포트는 기간을 입력한 뒤 별도 화면으로 나와 단계가 많고 표 글씨가 작음
  - 번역 화면은 접근 거부, 갱신 링크는 대시보드로 되돌아옴
  - 그룹 카드는 "참여하기"만 크게 보여 둘러보기가 어려움
- **발견한 좋은 점** [추정]
  - 인맥 카드 → 4버튼 팝업 구조는 관계 중심 앱에 잘 맞음
  - 목표를 "목표 / 실제 / 달성 방법" 3행으로 적는 구조는 월간 목표에 응용 가능
- **격려와 경쟁** [확인]: 카드는 "내 숫자"(건수, 금액)를 보여 주고, 등급 배지, 트래픽 라이트, 부의장 리포트 같은 순위·감독 도구가 있음. 성장 격려보다 정량 실적 관리 쪽이라 WMTO의 "경쟁이 아닌 격려"와 충돌하는 부분이 많음

## 6. WMTO 비교

### 6-1. 이미 있고 비슷한 것 (그대로 두어도 됨)

| BNI | WMTO | 판단 |
|---|---|---|
| 프로필, 완성도 | 역할별 프로필 | 유지 |
| 1:1 미팅 기록 | 멘토링 기록 | 유지 (BNI는 입력이 단출함) |
| 리퍼럴 슬립 | 매칭 요청, 리퍼럴 | 유지, 6-4처럼 변형 |
| 감사장 TYFCB | 감사 편지 | 유지 (WMTO는 금액 대신 이야기) |
| 이벤트 목록·상세 | 모임 일정·출석 | 유지, 마감·최소 인원 규칙 참고 |
| 활동 리포트 | 나눔 리포트 | 유지 |

### 6-2. 빠진 것 (우선순위)

- **높음**
  - 첫 화면 "오늘 할 일" (BNI에도 없어 차별점이 됨)
  - 프로필 완성도 안내
  - 비지터(참관자) 초대·등록 흐름과 후속 이메일
  - 이벤트 상세의 등록 신청, 마감, 최소 모집 규칙
  - 추천사(감사) 한 줄 쓰기와 요청
  - 월간 목표를 "목표 / 지금 / 어떻게 할지" 3칸으로 적는 화면
- **중간**
  - 인맥 요청·승인
  - 업데이트 피드(누가 무엇을 했는지)
  - 리퍼럴 상태 추적
  - 챕터 단위 공지
  - 인물 검색
- **낮음**
  - 관심사 그룹
  - 사진 갤러리
  - 인쇄·파일 저장 리포트
  - CEU 학점 관리 (아카데미 이수 표시로 충분)

### 6-3. 가져오면 안 되는 것과 이유

- **TYFCB 금액 집계와 금액 카드**: 누가 얼마를 줬고 벌었는지로 서열이 생겨 "More Blessed to Give"와 충돌
- **트래픽 라이트, 부의장 리포트, 개인 주차별 실적표**: 색깔 순위와 감시는 비교와 압박을 만듦. 성장 단계 이름으로 격려하는 원칙과 반대
- **등급 배지와 순위**: 경쟁
- **Gains·Tops 프로필 등 사업 목표 공개**: 선교사 정보 노출 위험, 공개 범위를 엄격히
- **결석 리포트의 지적 구조**: 출석은 보되 안부와 기도 요청으로 다룸
- **글로벌 오픈 그룹**: 선교사 보호 때문에 공개 그룹은 부적합 [추정]

### 6-4. WMTO 버전으로 바꿔 가져올 것

1. **리퍼럴 슬립 → 매칭 요청(선교사 ↔ 사업가)**
   - 입력: 요청 종류(기술 전수 / 경영 코칭 / 판로 연결 / 전문 자문), 요청자(선교사), 받는 멘토(선택, 비우면 운영진이 배정), 필요한 도움 한 문장, 기도제목(선택), 희망 시기, 연락 방법, 공개 범위
   - 상태: 요청됨 → 수락됨 → 진행 중 → 완료 / 다른 길 찾음 (정죄 없는 이름)
   - 필수는 3~4개로 제한
2. **TYFCB → 감사 편지**: 금액 없음. "누가 어떤 도움을 받았나" 한 문장 + 선택 사진·기도제목. 받는 사람은 멘토·후원자. 추천사처럼 필수 1칸을 기본으로
3. **1:1 → 멘토링 기록**: 만난 사람, 날짜, 주제 + "이번에 나눈 것 / 다음에 할 것 / 기도제목"
4. **비지터 등록 → 참관자 초대**: 이름·연락처·초대한 사람·참석 형태만 받고, 초대 링크 발송과 참관 후 후속 안내를 자동화
5. **리퍼럴 추적지 → 매칭 진행 보기**: 상태 변화를 시간순으로(점수 없음)
6. **프로필 완성도 → 첫 30일 체크리스트**: 퍼센트 대신 단계별 안내
7. **이벤트 상세 → 모임 상세**: 일시, 장소, 온라인 링크, 최소 인원, 마감, 한 번에 누르는 출석
8. **인물 검색 → 멘토·선교사 찾기**: 키워드 + 업종, 지역, 언어, 기여 방식, 선교 지역
9. **인맥 카드 4버튼 → 멤버 카드**: 프로필 보기 / 감사 편지 보내기 / 도움 요청하기 / 메시지
10. **챕터 목표 → 챕터·선교지 월간 목표**: 점수 비교 없이 "이번 달 함께 하려는 것"만 (목표 / 지금 / 어떻게)

### 6-5. 선교사·후원자 첫 화면 제안 [추정]

- **선교사(Partner)**: 위에서부터
  1. 이번 달 자립 리포트 쓰기(진행 상태)
  2. 내 멘토와 다음 만남
  3. 대기 중인 매칭 요청과 답변
  4. 받은 응원과 기도제목
  5. 성장 단계(Ready → Launch → Growing → Self-Sustaining)
- **후원자(Sponsor)**: 위에서부터
  1. 후원한 선교사의 최근 소식(감사 편지, 자립 단계)
  2. 순환 기금 사용 현황(금액 순위 없이)
  3. 감사 편지 도착 알림
  4. 다음 후원 기회(캠프 등)
- 두 역할 모두 BNI의 숫자 카드 7장 대신 **카드 3~4개**로 줄입니다.

## 8. 가장 먼저 반영하면 좋은 5가지

1. 첫 화면 "오늘 할 일" 카드(역할별로 다르게)
2. 매칭 요청 화면을 필수 3~4개로 짧게, 상태 이름은 정죄 없이
3. 감사 편지의 "누가 도움받았나" 한 줄(추천사처럼 필수 1칸)과 "저장 후 새로 만들기" 연속 입력
4. 첫 30일 오리엔테이션 체크리스트(프로필 % 대체)
5. 멘토링 기록에 "다음에 할 것·기도제목" 추가(BNI에 없는 후속 항목이라 차별점)
