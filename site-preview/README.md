# 정적 미리보기

- `index.html` : **CBC(크리스천 비즈니스 커넥트)** 홈페이지 스냅샷(컨셉 소개·사진 포함). 기본 화면입니다. 사진은 `images/cbc/`.
- `wmto/index.html` : 선교 사역 **WMTO** 사이트 스냅샷(이전 버전). CBC 홈페이지의 "선교 사역(WMTO)" 링크로 들어갑니다.

로그인·신청·영문 페이지 같은 서버 기능은 동작하지 않고, 해당 링크는 실제 사이트(https://wmto.vercel.app)로 이동합니다.
실제 사이트(`apps/web`)를 바꾸면 이 파일도 다시 만들어야 최신 모습이 됩니다.
